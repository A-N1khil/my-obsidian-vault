## Problem Statement
The set `[1, 2, 3, ..., n]` contains a total of `n!` unique permutations.

By listing and labeling all of the permutations in order, we get the following sequence for `n = 3`:
1. `"123"`
2. `"132"`
3. `"213"`
4. `"231"`
5. `"312"`
6. `"321"`

Given `n` and `k`, return the `kth` permutation sequence.

**Example 1:**

**Input:** n = 3, k = 3
**Output:** "213"

**Example 2:**

**Input:** n = 4, k = 9
**Output:** "2314"

**Example 3:**

**Input:** n = 3, k = 1
**Output:** "123"

## Solution
```java
public String getPermutation(int n, int k) {
	StringBuilder result = new StringBuilder();
	boolean[] visited = new boolean[n + 1];

	// Pre compute factorials
	int[] factorial = new int[n + 1];
	Arrays.fill(factorial, 1);
	int f = 1;
	for (int i = 1; i <= n; i++) {
		f *= i;
		factorial[i] = f;
	}

	for (int pos = 1; pos <= n; pos++) {
		for (int i = 1; i <= n; i++) {
			if (!visited[i]) {
				int fact = factorial[n - pos];
				if (k > fact) {
					k -= fact;
				} else {
					result.append(i);
					visited[i] = true;
					break;
				}
			}
		}
	}
	return result.toString();
}
```

## Explanation

Instead of finding all the factorials, we are only interested in the $k^{\text{th}}$ factorial. So, we check how $k^{\text{th}}$ factorial is built up. We know that the permutations are arranged in descending order and the list of numbers are $[1, 2, \dots n]$ 

For any position we select, the remainder of the digits can be arranged in $(n - 1)!$ ways. For the case of $n=3$, we can fix either 1, 2 or 3 and the remaining numbers can be arranged in $(3-1)! = 2! = 2$ ways. Arranging that in ascending order, we get the first two permutations with 1, the next 2 with 2 and the last 2 with 3

Generalizing, we get the number of permutations remaining as $(n-p)!$ where $p$ is the position as we move along

Considering the Example 2, we have $n = 4, k = 9$ 

#### $p=1$ 
Digits starting ($p=1$) with 1 take up $(n-p)! = (4 - 1)! = 3! = 6$ permutations. Since $k=9<6$, we can skip 1, after having $k = k - 6 = 9 - 6 = 3$

Since $k = 3 < 6$, we know that the 9<sup>th</sup> permutation will start with 2, so we mark 2 as visited and add it to our result, breaking the inner loop

#### $p=2$
1. $(n - p)! = (4-2)! = 2! = 2 > k$
	So, 1 cannot be in the second digit as well $k = k - 2 = 1$
2. 2 is marked as visited so we skip it
3. $k = 1 < 2$ so, the second digit is 3, add it to the result

#### $p = 3, 4$
Since, $k = 1$, we have to pick the next smallest number. 2 and 3 are already visited, which leaves us with 1 and 4 and to get the smallest number, we need to arrange them in ascending order, which leaves us with **2314**
