## Problem Statement
Given an integer array `nums`, rotate the array to the right by `k` steps, where `k` is non-negative.

**Example 1:**

**Input:** $nums = [1,2,3,4,5,6,7], k = 3$
**Output:** $[5,6,7,1,2,3,4]$
**Explanation:**
rotate 1 steps to the right: [7,1,2,3,4,5,6]
rotate 2 steps to the right: [6,7,1,2,3,4,5]
rotate 3 steps to the right: [5,6,7,1,2,3,4]

**Example 2:**

**Input:** $nums = [-1,-100,3,99], k = 2$
**Output:** `[3,99,-1,-100]`
**Explanation:** 
rotate 1 steps to the right: `[99,-1,-100,3]`
rotate 2 steps to the right: $[3,99,-1,-100]$

**Constraints:**
- `1 <= nums.length <= 105`
- `-231 <= nums[i] <= 231 - 1`
- `0 <= k <= 105`

**Follow up:**

- Try to come up with as many solutions as you can. There are at least **three** different ways to solve this problem.
- Could you do it in-place with `O(1)` extra space?

## Solution (In Place Swapping)

```java
void reverseArray(int start, int end, int[] nums) {
	while (start < end) {
		int temp = nums[start];
		nums[start] = nums[end];
		nums[end] = temp;

		start++;
		end--;
	}
}

public void rotate(int[] nums, int k) {
	// k can be larger than the size of the array, so find the final k by modulo
	int length = nums.length;
	k %= length;

	// Reverse the entire array so that backward elements can come front
	reverseArray(0, length - 1, nums);

	// Reverse the first k elements => Gives back the correct order in the front of the array
	reverseArray(0, k - 1, nums);

	// Finally reverse the remaining elements to get the correct order in the back of the array
	reverseArray(k, length - 1, nums);
}
```


## Explanation

If we were to know the final indices of the elements in the array, it would be easy to swap in place. Since the question asks for rotation, it is very clear to assume that the back of the array will take up the space in the front

Example - $[1, 2, 3, 4, 5, 6, 7]$
1. We start by reversing the entire array - $[7, 6, 5, 4, 3, 2, 1]$
2. If we take a look at the array now, we can see two clear zones being formed
	$[\underbrace{7, 6, 5,}_{\text{should be [5, 6, 7]}} \quad \underbrace{4, 3, 2, 1}_{\text{should be [1, 2, 3, 4]}}]$ 
3. Hence, we reverse the individual parts again, which are $k$ and $n-k$ 
	$[\underbrace{7, 6, 5,}_{k} \quad \underbrace{4, 3, 2, 1}_{n-k}]$
4. Finally, we get - $[5, 6, 7, 1, 2, 3, 4]$
