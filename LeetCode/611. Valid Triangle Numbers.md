## Problem Statement
Given an integer array `nums`, return _the number of triplets chosen from the array that can make triangles if we take them as side lengths of a triangle_.

**Example 1:**

**Input:** `nums = [2,2,3,4]`
**Output:** 3
**Explanation:** Valid combinations are: 
2,3,4 (using the first 2)
2,3,4 (using the second 2)
2,2,3

**Example 2:**

**Input:** `nums = [4,2,3,4]`
**Output:** 4

## Solution
```java
public int triangleNumber(int[] nums) {
		Arrays.sort(nums);
		int count = 0;
		for (int large = nums.length - 1; large >= 2; large--) {
			int left = 0, right = large - 1;
			while (left < right) {
				if (nums[left] + nums[right] > nums[large]) {
					/*
					 * Since the array is sorted, all numbers from left+1 will be greater nums[left]
					 * Thus nums[left+1] + nums[right] >= nums[left] + nums[right]
					 * Hence, all of them can form triangles
					 */
					count += right - left;
					// Move to the next smallest right
					right--;
				} else {
					// Sum is too small, need bigger numbers
					left++;
				}
			}
		}
		return count;
	}
```

## Explanation

A triangle is formed when the sum of any two sides is greater than the third side. Assuming side lengths of $a, b, c$
$$
a + b > c
$$
$$
a + c > b
$$
$$b + c > a$$
Assuming, we sort the array and consider `arr = [a, b, c]`
Then, $a \leq b \leq c$

Having this with us, all we need to find is a set of numbers for which $a + b > c$

---
1. Sort the array `nums`
2. Pick the largest number, i.e the last index of the array - this will be our third side
	1. Initialize `left = 0, right = largest - 1`
	2. Look for pairs of `nums[left]` and `nums[right]` that satisfy the triangle condition
	3. Suppose we get a pair of any $l \in \text{left},r \in \text{right}$  then all numbers between $l$ and $r$ will be counted as valid because the array is sorted
