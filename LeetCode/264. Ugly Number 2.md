## Problem Statement
An **ugly number** is a positive integer whose prime factors are limited to `2`, `3`, and `5`.

Given an integer `n`, return _the_ `nth` _**ugly number**_.

**Example 1:**

**Input:** n = 10
**Output:** 12
**Explanation:** `[1, 2, 3, 4, 5, 6, 8, 9, 10, 12]` is the sequence of the first 10 ugly numbers.

**Example 2:**

**Input:** n = 1
**Output:** 1
**Explanation:** 1 has no prime factors, therefore all of its prime factors are limited to 2, 3, and 5.

## Solution
```java
public int nthUglyNumber(int n) {
	int[] dp = new int[n];
	int i2 = 0, i3 = 0, i5 = 0;
	dp[0] = 1;
	for (int i = 1; i < n; i++) {
		int n2 = dp[i2] * 2;
		int n3 = dp[i3] * 3;
		int n5 = dp[i5] * 5;
		int nextUgly = Math.min(n2, Math.min(n3, n5));
		dp[i] = nextUgly;

		if (nextUgly == n2) {
			i2++;
		}

		if (nextUgly == n3) {
			i3++;
		}

		if (nextUgly == n5) {
			i5++;
		}
	}
	return dp[n - 1];
}
```

## Explanation

We start with 1, the first prime number with no factors. Ugly numbers are supposed to have prime factors of 2, 3, and 5, so we can keep multiplying the next smallest number by these factors and get our intended result.

We also initialize 3 pointers for 2, 3, and 5, respectively, as they will help us in counting further.

### Pass 1

`dp = [1]`

1. Starting with 1, and `i2 = i3 = i5 = 0`, which points to `dp[0] = 1`
2. We multiply `dp[i2] * 2 = 2`, `dp[i3] * 3 = 3`, and `dp[i5] * 5 = 5`
3. Since the next ugly number should come in sequence, we find the minimum of these values, which comes out to be 2
4. Hence, we keep the i<sup>th</sup> ugly number as 2
5. Now, we check from which index we got the number, in this pass it is 2, so we increment `i2`

### Pass 2

`dp = [1, 2]`

1. We again do Step 2 from the previous pass, this time getting results of 4, 3, and 5. (Since `i3` and `i5` are still at 0)
2. This time, the minimum is 3, so we add 3 to `dp` and increment `i3`
3. `dp = [1, 2, 3]`
