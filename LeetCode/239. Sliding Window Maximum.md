## Problem Statement
You are given an array of integers `nums`; there is a sliding window of size `k` that is moving from the very left of the array to the very right. You can only see the `k` numbers in the window. Each time the sliding window moves right by one position.

Return _the max sliding window_.

**Example 1:**

**Input:** `nums = [1,3,-1,-3,5,3,6,7], k = 3`
**Output:** `[3,3,5,5,6,7]`
**Explanation:** 
Window position                Max
---------------               -----
[1  3  -1] -3  5  3  6  7       **3**
 1 [3  -1  -3] 5  3  6  7       **3**
 1  3 [-1  -3  5] 3  6  7      ** 5**
 1  3  -1 [-3  5  3] 6  7       **5**
 1  3  -1  -3 [5  3  6] 7       **6**
 1  3  -1  -3  5 [3  6  7]      **7**

**Example 2:**

**Input:** `nums = [1], k = 1`
**Output:** `[1]`

## Solution
### My Solution - $O(n \times \log k)$
```java
int[] result = new int[nums.length - k + 1];
int resultIndex = 0;
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> {
	if (a[0] == b[0]) {
		return a[1] - b[1]; // Ascending index if values are equal
	}
	return b[0] - a[0]; // Max value at the top
});

// Add the first sliding window - 1 into the queue
for (int i = 0; i < k - 1; i++) {
	pq.offer(new int[]{nums[i], i});
}

// Start with k - 1
for (int i = k - 1; i < nums.length; i++) {
	pq.offer(new int[]{nums[i], i});
	// Remove elements outside window
	while (pq.peek()[1] <= i - k) {
		pq.poll();
	}
	result[resultIndex++] = pq.peek()[0];
}
return result;
```

## Explanation

### My Solution
1. We create a [Priority Queue]([[Queues#Priority Queue]]) first, and we add a custom Comparator to it.
	1. Reset the comparator to return the maximum present in the queue.
	2. In case of a tie, the comparator should sort in ascending order of the position. The numbers are present in the area. This way, we will have smaller indices at the bottom of the queue and can be removed first as the window progresses
2. We add the first $k-1$ elements to the [[Sliding Window]]
3. Starting off at $k$ we first add the array containing `[nums[i], i]` to the window (our Priority Queue)
4. We run a loop which removes all those elements whose index is not covered in the window
5. We find the maximum element in the Queue and add it to the result.
