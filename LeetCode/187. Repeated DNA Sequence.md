## Problem Statement
The **DNA sequence** is composed of a series of nucleotides abbreviated as `'A'`, `'C'`, `'G'`, and `'T'`.
For example, `"ACGAATTCCG"` is a **DNA sequence**.
When studying **DNA**, it is useful to identify repeated sequences within the DNA.
Given a string `s` that represents a **DNA sequence**, return all the **`10`-letter-long** sequences (substrings) that occur more than once in a DNA molecule. You may return the answer in **any order**.

**Example 1:**
**Input:** `s = "AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT"`
**Output:** `["AAAAACCCCC","CCCCCAAAAA"]`

**Example 2:**
**Input:** `s = "AAAAAAAAAAAAA"`
**Output:** `["AAAAAAAAAA"]`

**Constraints:**
- `1 <= s.length` $\leq 10^5$
- `s[i]` is either `'A'`, `'C'`, `'G'`, or `'T'`.

## Solution
```java
public List<String> findRepeatedDnaSequences(String s) {  
  
    // Answer List  
    List<String> result = new LinkedList<>();  
  
    // Corner case - Empty String  
    if (s.length() < 10) {  
       return result;  
    }  
  
    Map<String, Integer> map = new HashMap<>();  
  
    for (int i = 0; i < s.length() - 10; i++) {  
       String window = s.substring(i, i + 10);  
       map.put(window, map.getOrDefault(window, 0) + 1);  
       if (map.get(window) == 2) {  
          result.add(window);  
       }  
    }  
  
    return result;  
}
```

## DSA Info
1. We need to find a subsequence of exactly **10** characters $\rightarrow$ [[Sliding Window#Fixed Size Sliding Window]]
2. Since we want to know if there is a repeated occurrence, we need to count $\rightarrow$ [[Maps#HashMaps]]

## Explanation

1. Create a `HashMap` to keep a counter of windows. Every `window` of length 10 is a key.
2. Run a loop $i$ from $0\dots\text{len}(s)-9$ 
	1. Create a window from $[i, i+10]$
	2. Increment the count of `key(window)` in the map
		- If `count == 2` $\Rightarrow$ add it to the result
3. Return the result
