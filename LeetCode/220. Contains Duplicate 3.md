## Problem Statement
You are given an integer array `nums` and two integers `indexDiff` and `valueDiff`.

Find a pair of indices `(i, j)` such that:
- `i != j`,
- `abs(i - j) <= indexDiff`.
- `abs(nums[i] - nums[j]) <= valueDiff`, and

Return `true` _if such pair exists or_ `false` _otherwise_.

**Example 1:**

**Input:** nums = `[1,2,3,1]`, indexDiff = 3, valueDiff = 0
**Output:** true
**Explanation:** We can choose (i, j) = (0, 3).
We satisfy the three conditions:
$i \neq j \rightarrow 0 \neq 3$
$\text{abs}(i - j) \Leftarrow \text{indexDiff} \rightarrow \text{abs}(0 - 3) \leq 3$
$\text{abs}(\text{nums}[i] - \text{nums}[j]) \Leftarrow \text{valueDiff} \rightarrow \text{abs}(1 - 1) \leq 0$

**Example 2:**

**Input:** nums = `[1,5,9,1,5,9]`, indexDiff = 2, valueDiff = 3
**Output:** false
**Explanation:** After trying all the possible pairs (i, j), we cannot satisfy the three conditions, so we return false.

## Solution
```java
TreeSet<Integer> window = new TreeSet<>();  
for (int i = 0; i < nums.length; i++) {  
  
    // First, we check if we have a value in the range nums[i] - valueDiff 
    // to nums[i] + valueDiff  
    Integer ceiling = window.ceiling(nums[i] - valueDiff);  
  
    if (ceiling != null && ceiling <= (nums[i] + valueDiff)) {  
       return true;  
    }  
  
    // Add element to window  
    window.add(nums[i]);  
  
    // Remove any elements not in the range  
    if (i >= indexDiff) {  
       window.remove(nums[i - indexDiff]);  
    }  
}  
  
// Fallback  
return false;
```

We need something that can keep the elements sorted as we pass the window through the range of `indexDiff` $\Rightarrow$ [[Sets#TreeSets]]

## Explanation
- Looking at the conditions, we keep a [[Sliding Window]] that covers the range $\{i , \text{indexDiff}\}$.  
- In that [[Sliding Window]], we need to keep a lookout for elements that are `valueDiff` closer to the current element in the array.
	- Since we are using *Math.abs()*, we need to check that any element $x$ basically should be between the range of $[\text{nums}[i] - \text{valueDiff}, \text{nums}[i] + \text{valueDiff}]$ 
	- We create a [[Sets#TreeSets]] Sliding window to enable us to extract elements in the range
	- Since we only have to worry about existence, any number satisfying our condition will work here
- As we iterate the array, we add `nums[i]` into the TreeSet
