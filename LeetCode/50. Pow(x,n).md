## Problem Statement
Implement [pow(x, n)](http://www.cplusplus.com/reference/valarray/pow/), which calculates `x` raised to the power `n` (i.e., `xn`).

## Solution
```java
public double myPow(double x, int n) {
		if (x == -1 || x == 0 || x == 1) {
			return x;
		}
		if (n == 0) {
			return 1;
		}
		return n < 0 ? (1 / pow(x, -(long) n)) : pow(x, n);
	}

double pow(double base, long exponent) {
	double result = 1.0;
	while (exponent > 0) {
		if ((exponent & 1) == 1) {
			result *= base;
		}
		base *=  base;
		exponent >>= 1;
	}
	return result;
}
```

## Explanation

On the surface, this might look like a simple recursion problem, but this is not as easy. Recursion will cause StackOverflow issues when $n \rightarrow 2^{31}-1$
Suppose we have a number $x$ and a power of $11$, then $x^{11}$ can be written as
$$
x^{11} = x^8 \times x^2 \times x
$$

or, to be more clear,
$$
(11)_{10} = (1011)_2
$$
$$
x^8 = (x^2)^3
$$
