## Problem Statement


## Solution

The helper function `squareSum` calculates the sum of squares of the digits
```java
int squareSum(int n) {  
    int sum = 0;  
    while (n > 0) {  
       int digit = n % 10;  
       sum += digit * digit;  
       n /= 10;  
    }  
    return sum;  
}  
```

#### Approach 1 - Using [[Sets]] (Slowest)
```java
public boolean isHappy_set(int n) {  
    Set<Integer> visited = new HashSet<>();  
    while (n > 9 && !visited.contains(n)) {  
       visited.add(n);  
       n = squareSum(n);  
    }  
    return n == 1 || n == 7;  
}  
```

#### Approach 2 - [[Two Pointer Method]]  (Medium)
```  java
public boolean isHappyTwoPointers(int n) {  
    int slow = n, fast = n;  
    do {  
       slow = squareSum(slow);  
       fast = squareSum(squareSum(fast));  
    } while (slow != fast && fast != 1);  
    return fast == 1;  
}  
```

#### Approach 3 - [[Recursion]] (Fastest)
```java
public boolean isHappyRecursive(int n) {  
    if (n == 1 || n == 7) {  
       return true;  
    } else if (n < 10) {  
       return false;  
    } else {  
       int sum = squareSum(n);  
       return isHappyRecursive(sum);  
    }  
}
```


## Explanation

#### 1. Recursion with Single-Digit Observation

```java
if (n == 1 || n == 7) return true;
if (n < 10) return false;
return isHappyRecursive(squareSum(n));
```
- Uses a mathematical property:
    - Every happy number eventually reaches `1`.
    - Every happy number that becomes a single digit must be either `1` or `7`.
    - Any other single digit (`2,3,4,5,6,8,9`) is unhappy.

**Pros**
- Simplest solution.
- Usually fastest in practice.
- Only one `squareSum()` per step.
- No extra data structures.

**Cons**
- Relies on a problem-specific observation (`1` and `7`).
- Uses recursion (small stack overhead).

**Complexity**
- Time: Effectively $O(1)$ for bounded integers.
- Space: **O(depth)** recursion stack.

---

### 2. HashSet Cycle Detection

```java
Set<Integer> visited = new HashSet<>();
while (n > 9 && !visited.contains(n)) {
    visited.add(n);
    n = squareSum(n);
}
```

**Idea**
- Store every number seen.
- If a number repeats, you've entered a cycle → unhappy.
- If you reach `1`, it's happy.

**Pros**

- Easy to understand.
- Works for any sequence where cycle detection is needed.
- Doesn't require special knowledge about happy numbers.

**Cons**

- Hash lookups on every iteration.
- Extra memory usage.
- Usually slower than recursion and often slower than Floyd.

**Complexity**
- Time: $O(k)$ where `k` is the sequence length.
- Space: $O(k)$.

---

### 3. Floyd's Cycle Detection (Slow/Fast Pointers)

```java
slow = squareSum(slow);
fast = squareSum(squareSum(fast));
```

**Idea**

- Treat the sequence as a linked list.
- Happy numbers end at `1`.
- Unhappy numbers enter a cycle.
- Use slow/fast pointers to detect the cycle without extra memory.

**Pros**
- Elegant cycle-detection technique.
- No extra space.
- General-purpose algorithm.

**Cons**
- Calls `squareSum()` three times per iteration.
- Slightly more work than recursion.

**Complexity**

- Time: **O(k)**.
- Space: **O(1)**.
